# 实时天气地球 · 架构结论与实测记录

> 2026-07-31 收集阶段。**前端未开工**。本文是「能不能做、怎么做」的实测答案,
> 数据源清单见同目录 01(天气 API)、02(卫星影像图层)。

## 一、核心问题:静态站能不能做实时天气地球?

**能,但必须分两条路走。** 本项目是 GitHub Pages 上的自包含静态页,没有后端,
这个约束决定了一切。以下结论全部是实测得出,不是文档转述。

### 路线 A:单点实时(运行时直接调,零成本)
用户点地球上某处 → 浏览器直接请求 Open-Meteo → 立刻显示该点实时天气。

- **免 API key**,**CORS 全开**:实测响应头 `access-control-allow-origin: *`,
  `access-control-allow-methods: GET, POST, OPTIONS` —— 静态页可直接调,无需代理、无需后端。
- 数据源本身是 ECMWF IFS + DWD ICON + NOAA GFS 等多模式融合,最细到 1~2km。
- 密钥不用塞进公开页面,没有被盗刷的风险。

### 路线 B:全球格点预烘(定时任务,访客零调用)
"温度场铺满整个地球"这种效果**不能每个访客现拉**,原因是实测到的三道限制:

| 限制 | 实测结果 |
|---|---|
| GET 请求点数 | 约 400 点封顶,再多 URL 超长直接 **HTTP 414** |
| POST 请求点数 | **1000 点/次**,超过服务端明确报 `Only up to 1000 locations` |
| 速率限制 | 分钟/小时/天三级。连发 1000 点大批量必触发 **HTTP 429**,重试要等 60 秒以上 |

一次全球 4° 格点(3690 点)= 4 次请求 ≈ 4 分钟(受限流拖累)。
若每个访客都跑一遍,免费额度瞬间打爆。**正解:GitHub Actions 定时跑,产物随站点分发。**

## 二、已产出的实测数据

### `data/weather_grid.json` — 全球格点快照(85 KB)
```
格点 41×90 = 3690 点(4° 间隔,南北纬 80° 内)
要素:气温 t2m / 风速 ws / 风向 wd / 云量 cc / 降水 pr / 相对湿度 rh
结构:行优先展平数组(纬度北→南 × 经度西→东),便于直接喂 canvas 做色斑图
```
**质量验证**(2026-07-31 00:45 UTC 快照):
- 纬向平均气温:+80°→1.1℃、+40°→23.4℃、赤道→26.2℃、-40°→11.7℃、-80°→-46.9℃
  —— 七月北半球夏季的真实梯度,南北不对称正确
- 赤道太平洋 28.3℃ 且云量 100% —— 热带辐合带特征
- 南极内陆 -45.9℃、风 36 km/h —— 下降风特征
- 青藏高原 7.9℃ —— 高原降温正确
- 全球气温范围 -71.0 ~ 40.5℃

### `data/weather_cities.json` — 58 座城市实时天气
覆盖各大洲 + 极端点位(麦克默多站 -37.3℃、朗伊尔城 8.8℃、乌斯怀亚、复活节岛…)。
悉尼 14℃(南半球冬)vs 北京 29.6℃(北半球夏)—— 季节一致性验证通过。

## 三、体积与更新频率建议

| 格点间隔 | 点数 | 请求次数 | 估算体积 | 适用 |
|---|---|---|---|---|
| 4° | 3,690 | 4 | 85 KB | 全球温度场底图,够用 |
| 2° | 14,760 | 15 | ~340 KB | 更细腻,cron 约 15 分钟 |
| 1° | 58,320 | 59 | ~1.3 MB | 接近模式原生分辨率,cron 约 1 小时 |

更新频率建议 **3~6 小时**(数值预报模式本身也就每 6 小时更新一轮),
足够"实时"又不浪费额度。

## 四、复跑命令

```bash
python tools/fetch_weather.py                # 4° 全球格点
python tools/fetch_weather.py --step 2       # 2° 更细格点
python tools/fetch_weather.py --cities       # 城市点位天气
```
脚本内置限流处理:遇 429 自动等 65 秒重试,批间隔 12 秒。

## 五、待前端实施时的设计要点

1. **温度场**:格点数组 → canvas 逐像素双线性插值 → 色斑图 → 当球面贴图叠加。
   配色建议用气象界通行的发散色标(蓝-白-红),而非彩虹色(彩虹色有感知欺骗性)。
2. **风场**:有风速+风向,可做 earth.nullschool 那种粒子流线动画(粒子沿风矢量移动 + 拖尾衰减)。
3. **云层**:两条路——格点云量做半透明白色叠加(简单);或用卫星真实云图贴图(真实,见 02 报告)。
4. **点击查询**:走路线 A,用户点哪查哪,永远是当下最新。
5. **时间戳展示**:数据自带 UTC 时刻,界面要显示"数据时刻",别让人误以为是此刻实况。
6. **许可**:Open-Meteo 免费额度限非商用,需署名。上线前确认展示方式合规。
